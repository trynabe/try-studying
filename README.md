# Try-Studying

by trynabe

เว็บสรุป Computer Architecture (ITDS-211) ภาษาไทย รวมเนื้อหาทั้ง 8 บทไว้ในสมุดรายวิชา

- สรุป 117 หัวข้อ พร้อม 43 สูตรและตัวอย่างคำนวณ และภาพอธิบาย 11 ภาพ
- แบบทดสอบ 120 ข้อ: บทละ 15 ข้อ แบ่งเป็นง่าย 7 ปานกลาง 5 และยาก 3
- ตรวจคะแนนพร้อมเฉลย ฝึกข้อที่ตอบผิด และบันทึกคำตอบไว้ทำต่อ
- หน้าตา vintage ที่ปรับตามขนาดจอ พร้อมโหมดสว่างและโหมดมืด charcoal
- ฟอนต์ PT Serif และ Noto Serif Thai เก็บไว้ในโปรเจกต์
- ความก้าวหน้า คำตอบ และการตั้งค่าสีเก็บในเบราว์เซอร์ด้วย localStorage

## รันเว็บ

ใช้ Python 3 จากโฟลเดอร์โปรเจกต์:

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

เปิด [localhost:8000](http://localhost:8000) หรือใช้ `npm start` ไม่ต้องติดตั้ง dependencies หรือ build

## ตรวจแบบทดสอบ

ใช้ Node.js 22 ขึ้นไป:

```sh
npm test
```

ตรวจจำนวนข้อและระดับความยาก การสลับตัวเลือก การทำต่อ การคิดคะแนน และการฝึกข้อที่ตอบผิด

## ไฟล์หลัก

- `dist/`: เว็บและ assets พร้อมนำไปวางบน static hosting
- `dist/review-data.json`: เนื้อหาสรุป 8 บท
- `dist/quiz-data.json`: ชุดคำถามและเฉลย
- `study-review-8-chapters.md`: สรุปในรูปแบบ Markdown
- `tests/quizzes.mjs`: ชุดตรวจแบบทดสอบ

ฟอนต์และไลบรารีภายนอกมีไฟล์ลิขสิทธิ์อยู่ใน `dist/fonts/` และ `dist/vendor/`
